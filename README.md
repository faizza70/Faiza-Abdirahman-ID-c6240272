# DataStructures_Assignment1And2
​A collection of Java programs implementing core OOP concepts such as Inheritance, Polymorphism, and Abstract Classes, including an Employee Salary Management System and a Hospital Medical Billing System.

​Java Object-Oriented Programming (OOP) Assignments
​This repository contains two Java projects focusing on core OOP principles:
​Employee Salary Management System (Assignment 1):
​Manages salaries for full-time, part-time, and manager employees.
​Utilizes Inheritance (extends, super), Method Overriding (@Override), and Polymorphism (Employee[] array).
​Hospital Medical Billing System (Assignment 2):
​Calculates medical service bills for consultations, laboratory tests, and ultrasounds.
​Utilizes Abstract Classes, Abstract Methods, and Concrete Subclasses.
